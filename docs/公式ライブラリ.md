# 公式ライブラリ

[English](libraries.md)

標準ライブラリ(`lib/`、`「名前」 を 読み込む` で使う)のほかに、suru-lang の organization には、それぞれのリポジトリに置いた小さなライブラリがあります。これらは標準ライブラリには入っていません。[kumu](https://github.com/suru-lang/suru/blob/main/README_jp.md#プロジェクトを組むkumu) のプロジェクトで `kumu 追加` して、名前で読み込みます。

```sh
kumu 追加 github.com/suru-lang/db
kumu 追加 github.com/suru-lang/sqlite
```

```suru
「蔵」 を 読み込んで 使う
「SQLite」 を 読み込んで 使う

主処理する とは 入出力手順
  db とは 「店.db」 を SQLite駆動 で DB開封した 結果
  db に 「CREATE TABLE IF NOT EXISTS 品 (名前 TEXT, 値段 REAL)」 を DB実行する
  db を DB閉鎖する
  「以上です」 を 表示する

主処理する
```

ライブラリの依存も kumu が取ってきます(たとえば `github.com/suru-lang/orm` を足すと 「蔵」 も来ます)。C のライブラリを呼ぶものは、そのライブラリをシステムに入れておきます。kumu は各ライブラリの `組.suru` の `外部依存` を確かめ、なければ入れ方を示します。詳しくは各ライブラリの README にあり、ほとんどは注釈から作った API のページが Read the Docs にあります。

## ウェブフレームワーク 屋台

[suru-lang/web](https://github.com/suru-lang/web)(`「屋台」`、する 0.11.0 以上)は、上のライブラリより大きなものです。http・雛形・台帳をまとめたウェブフレームワークです。【道】で道筋を1行に1つずつ並べ、それぞれの処理を書けば、インタプリタでもコンパイルしたバイナリでもサーバーが動きます。セッション・フォーム・クッキー・中継(ミドルウェア)・サーバーなしの道筋の試験も入っています。API: [docs](https://suru-lang-web.readthedocs.io/en/latest/)。

`kumu 新規 店 --対象 web` で、道筋・テンプレート・静的ファイル・試験のそろったウェブアプリができます。

```suru
「屋台」 を 読み込んで 使う
「標準」 を 読み込んで 使う

文脈 を 品表示する は HTTP内の応答 の 動作
c を 品表示する とは 「品 」 + （c から 「番号」 を 道引数取得する） + 「 です」 を 文字返答する

道群 とは 以下の【道】です
  GET  /品/:番号    品表示する
以上です

8080 を 道群 で 屋台開店する
```

## 自分で作る

`組.suru` があってタグを付けた Git のリポジトリなら、どれでも `kumu 追加` で足せます。中央の登録所はありません。[ライブラリを公開する](ライブラリを公開する.md)を見てください。
