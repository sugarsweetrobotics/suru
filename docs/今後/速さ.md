計画は #229。今は「同梱の suruc でコンパイルして動かす」で、C コンパイラがなければインタプリタです。

- C コンパイラがなくても速く: PyPI の `ziglang`(`zig cc` が clang)を追加の選択(`pip install suru-lang[…]`)にして、CC に使う。100 MB の取り込み(入れると 400 MB)、`zig cc` で実行時ライブラリと IR がつながるかは未確認

- 起動を速く: `suru` の起動口を小さいモジュールにして、コンパイルして動かすときは `suru.py`(約 0.03 秒)を読み込まない
- `suru --試験` も、同梱の suruc があれば `suruc --試験` で動かす
- Pyodide(playground)向けに、Python のインタプリタを速くする(`Interpreter.eval` の振り分けをクロージャにする。2〜3 倍の見込み)
- Go でインタプリタを書く(C コンパイラなしでも速いが、3つ目の実装になる)
