# 今後の候補: 他の言語から呼ぶ(共有ライブラリ)

- Python の包みを作る: ヘッダと同じ情報から、`ctypes` の型(`argtypes`・`restype`)と文字列の解放をすませた `keisan.py` を作る(`suruc --共有ライブラリ --python` など)
- 大きいスタックで動かす形: 今は呼んだ側のスレッドのスタックで動かすので、とても深い再帰はそのスタックの大きさまで。望むときだけ、大きいスタックのスレッドに移して動かす
- WebAssembly: `.wasm` に出して、ブラウザや Node から呼ぶ(GC とスレッドの作りを WebAssembly に合わせる)
- macOS の CI: `.dylib` は作りを書いたが、CI では Linux と Windows だけで試している
- 手札の取り出し関数を足す: バイト列・リストを番地と長さでまとめて取り出す(今は `keisan_get` で1つずつ)
- 組を C の構造体で渡す(C形 と同じ並び)。今は手札で渡し、`keisan_field` で読む
- Rust・Go の包み(bindgen を使わずに、型の付いた関数を作る)を例ではなくコンパイラで作る
- Node(`koffi` など)・C#(P/Invoke)の例
