# 今後の候補: 通信(ソケット)

今の「通信」は TCP(待ち受け・受け付け・こちらからつなぐ・行/バイト数/バイト列の受信・送信・切断・待機時間)と UDP(口・送信・受信・返信)、待ち受けるアドレスの指定、ポートと相手のアドレスの取得、ブロードキャスト・マルチキャスト・IPv6 です。計画 issue #123 は済みました。

- Unix ドメインソケット(同じ機械のプロセスどうし)
- 文字列の UDP送信する・UDP受信する のエラーの文を、中で呼ぶ組み込みの名前ではなく自分の名前で出す
- マルチキャストの届く範囲(IP_MULTICAST_TTL)と、自分にも届けるか(IP_MULTICAST_LOOP)、使うネットワークの口を選ぶ
- 「に」を省いたときに IPv4 と IPv6 の両方で待ち受ける(今は 0.0.0.0。`「::」` で IPv6 にすると Linux では両方)
