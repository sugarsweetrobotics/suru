# 今後の候補: 通信(ソケット)

今の「通信」は TCP だけです(待ち受け・受け付け・こちらからつなぐ・行/バイト数/バイト列の受信・送信・切断・待機時間)。

- UDP(`ポート を UDP待受開始する`・`データ を ホスト に ポート で UDP送信する`・`口 から UDP受信する` で送り主のホストとポートも受け取る)
- 待ち受けるアドレスを選ぶ(今は 0.0.0.0 だけ。`「127.0.0.1」 に 8080 で 待受開始する` で自分の中だけに)
- 待受口のポートを 0 にして OS に選ばせ、選ばれたポートを知る(テストで空いているポートを使うため)
- 相手のアドレスとポートを知る(getpeername。ログやアクセス制限のため)
- Unix ドメインソケット(同じ機械のプロセスどうし)
