# 今後の候補: 通信(ソケット)

今の「通信」は TCP(待ち受け・受け付け・こちらからつなぐ・行/バイト数/バイト列の受信・送信・切断・待機時間)と UDP(IPv4 の口・送信・受信・返信)、待ち受けるアドレスの指定、ポートと相手のアドレスの取得です。計画は issue #123。

- Unix ドメインソケット(同じ機械のプロセスどうし)
- UDP のブロードキャスト(SO_BROADCAST)とマルチキャスト(IP_ADD_MEMBERSHIP)
- IPv6 の口(今は TCP の待受口も UDP の口も IPv4 だけ)
- 文字列の UDP送信する・UDP受信する のエラーの文を、中で呼ぶ組み込みの名前ではなく自分の名前で出す
