# 今後の候補: マイコン

計画は [する をマイコンで動かす計画](https://claude.ai/artifact/V9YJPJA4fXcGKtYacWHVy5) にあります。段階1・2(kumu の 対象・書き込む と、Uno 向けの小さい する)は済みました。

- 実機の Uno・Nano で確かめる(今は simavr で L チカ・シリアル・時計を確かめただけ)
- `kumu 見る`(シリアルモニター)で、書き込んだ後の「表示する」をそのまま見る
- Arduino Mega(ATmega2560)・Leonardo(ATmega32U4)のピンの表と書き込み方
- 小さい する に 小数(AVR の float)、固定の大きさのリスト、文字列の変数を足すか
- シリアルの受信を割り込みとバッファにする、行で受け取る
- I2C・SPI・EEPROM・サーボのライブラリ
- STM32(言語の全部): 実行時を OS なしで組めるように分け、固定のヒープで GC を動かす
- ESP32: ESP-IDF の部品として組み、Wi-Fi 越しの通信まで使う(C3/C6 から)
- Python 版(`suru.py --翻訳`)にも小さい する の生成を足すか
