# 今後の候補: 外部の関数(C とのやりとり)

- 構造体を値で渡す・返す(suru-lang/suru#137): LLVM IR では呼び出しの決まり(x86-64 の System V・arm64 の AAPCS64)の割り振りを出す側がするため、今の「どの計算機でも同じ IR」をやめて、Python 版と Go 版の両方に割り振りを書くことになります。それまでは、kumu の Cソース に番地で受け渡す小さな C の関数を書き、C形 で読み書きします。C形 の並びをプログラムに書いた宣言で決められるようになれば、コンパイラが C の包みを作って clang に割り振りを任せる方法もあります
- 呼び戻し: 構造体を値で受け取る呼び戻し、レジスタに入らない数の引数、x86-64・arm64 以外の CPU
- C の型の名前(符号付き32 など)を外部の関数の宣言にも使えるようにする(今は 数・整数・小数・単精度 など)
- C形: `#pragma pack`・bit field・共用体
- 句読点の書き方で `nを確保するとは、外部の「SDL_malloc」。` と書けるようにする(今は「外部」と「の」に分かれてエラーになります。まとまり `以下の外部の入出力動作です。…以上です。` は句読点の書き方でも書けます)
- 1行の書き方(#173)の `受け取って` の短い別名 `受けて`
- 外部でないふつうの関数も型を定義の後ろに書けるようにする(本体の式の `で` の引数とぶつからない書き方を決める)
