# 今後の候補: スレッド

計画は7段階です。段階1(runtime の下ごしらえ)と段階2(並行開始する・合流する・並行実行する・並列写像する・コア数取得する)は済みました。

- 段階3: 通路(作成・送信・受信・閉鎖・通路処理)
- 段階4: ロックの中だけで行う 排他実行する、プロセスの中のセマフォ(枠)、スレッドどうしで共有する箱
- 段階5: HTTP を接続ごとにスレッドで答える
- 段階6: 本当の並列(全体ロックをやめ、IR に安全点を足し、全スレッドを止める GC にする)
- 段階7: 測って、スレッドごとの確保や印付けの並列化を決める
- 複数の通路を同時に待つ(select)、時間切れつきの受信(「ないかもしれない値」の型ができてから)
- 読み書きロック(共有メモリなど外のものを読むスレッドが多いとき。読取実行する・書込実行する)。する の値と箱は読むのにロックが要らないので後回し
