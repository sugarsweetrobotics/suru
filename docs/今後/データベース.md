# 今後の候補: データベース

データベースの層「蔵」(suru-lang/db)、駆動(suru-lang/sqlite・suru-lang/postgresql・suru-lang/mysql)、O/R マッパー「台帳」(suru-lang/orm)は #164 の計画で作りました。

- マイグレーション: 表に列を足す・名前を変える(今は `CREATE TABLE IF NOT EXISTS` だけ。版の表を持って、順に ALTER TABLE を流す)
- 接続プール: スレッドごとに DB接続 を貸し出す(「スレッド」と「セマフォ」で。SQLite は同じファイルに書くスレッドを1つにする)
- 日時の列: 「時間」の値を列に入れる(SQLite は文字列、PostgreSQL は TIMESTAMPTZ、MySQL は DATETIME。方言に型を足す)
- 遅延読み込み: 親を取ったとき、子は使うときに取る(今は 表関連取得する を自分で呼ぶ)
- 親と子を1回の問合せで取る(JOIN)、中間の表を使う多対多
- NULL にできる列: `有無` の値と DB無 の行き来(台帳生成でも書けるように)
- 台帳生成で、組と違う表の名前を書く
- プリペアドステートメントを使い回す(同じ文を何度も流すとき)
- MariaDB での CI(mysql の駆動は MySQL 8 だけで確かめている)
- SQLite のライブラリの候補は suru-lang/sqlite の README に書く
