# 今後の候補: IPC(プロセスどうし)

計画は6段階です(案: https://claude.ai/artifact/WdKdRfxaYSwT5KCojzqqj5 )。段階1(値の直列化、セマフォ内実行する と SEM_UNDO)は済みました。

- 段階2: 共有箱(`「共有箱」 を 読み込む`、作成・接続・読取・更新・書込・使用・削除。読み書きロックを中に持ち、頭に型の指紋とセマフォの識別子)
- 段階3: 読み書きロック(読取実行する・書込実行する、プロセスどうし)。スレッドどうしのものはスレッドの段階4と一緒に
- 段階4: パイプの通路(スレッドの通路と同じ型で、通路送信する・通路受信する をそのまま使う)と 子で実行する
- 段階5: 名前つきの通路(関係ないプログラムどうし。共有メモリの輪とセマフォ)
- 段階6: 固定の形の共有領域(C と共有する、速さが要るとき)
- 復元するときに型を確かめる(今は形の名前とフィールドだけ。型検査の結果をコンパイラから runtime へ渡す必要がある)
