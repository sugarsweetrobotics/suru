# 日本語関数型プログラミング言語「する」(プロトタイプ)

Python 3.10 以降だけで動くインタプリタです(外部ライブラリ不要。テストに pytest を使います)。

```sh
python3 suru.py examples/basic.suru   # ファイルを実行(トップレベルの式の値を1行ずつ表示)
python3 suru.py --検査 examples/basic.suru  # 実行せずに型の間違いを探す(--check も可)
python3 suru.py                       # 対話モード
python3 -m pytest tests               # テスト
```

## 例

```
a　と　b　を加算する　とは　a + b

引数　を三倍する　とは　引数　と　引数　を加算して　引数　を加算する

1　と　2　を加算する      # → 3
5　を三倍する             # → 15
```

```
a を b で 割る数にする とは a / b
2 で 10 を 割る数にする              # → 5(助詞で引数が決まるので語順は自由)

リスト とは 1 と 2 と 3
リスト の それぞれ を 三倍する        # → （3 と 6 と 9）
リスト から 偶数判定すること で 選別する
5 に （1 を 加算すること） を 適用する  # → 6
```

空白や改行を使わず、句読点で詰めて書くこともできます(両方の書き方を同じファイルで混ぜてもかまいません)。

```
aとbを加算するとは、a+b。引数を三倍するとは、引数と引数を加算して、引数を加算する。
1と2を加算する。5を三倍する。                         # → 3、15
aとbを平均するとは、合計/2。ただし、合計とは、a+b。   # 局所定義は「ただし」で
```

組(名前付きタプル)、選択肢のある型、パターンマッチ、性質(型クラス)も使えます。

```
図形 とは 半径 の 円 か 幅 と 高 の 長方形

形 を 面積にする とは
  もし 形 が
    半径 の 円 ならば 3 * 半径 ^ 2
    幅 と 高 の 長方形 ならば 幅 * 高

5 の 円 を 面積にする                        # → 75
幅 は 2 で 高 は 3 の 長方形 を 面積にする    # → 6
```

引数に値や形を書くと、場合ごとに関数を定義できます。パターンには「かつ」で条件を付けられます。

```
0 を 階乗する とは 1
n を 階乗する とは n * （n - 1 を 階乗する）

空 を 合計する とは 0
先頭 は x で 残り は 他 を 合計する とは x + （他 を 合計する）

形 を 分類する とは
  もし 形 が
    半径 の 円 かつ 半径 >= 10 ならば 「大きい円」
    半径 の 円 ならば 「円」
    そうでなければ 「長方形」
```

「…である」で終わる名前は述語(真か偽を返す関数)で、主語を「が」で受けます。

```
n が 偶数である とは n % 2 が 0
もし n が 偶数である ならば 「偶」 そうでなければ 「奇」
3 が 偶数でない                                # → 真
リスト から 偶数であること で 選別する
```

画面への出力や入力のような副作用は「動作」という値で扱い、「手順」で順に行います。

```
挨拶するとは、手順（
  名前とは、「お名前は? 」を入力した結果。     # 「…した 結果」で動作の結果を受け取る
  「こんにちは、」+名前+「さん」を表示する。
  名前の長さを結果にする）。
挨拶してから、表示する。                       # 「してから」は前の動作の結果を「を」に渡す
「はじめ」を表示する。それから、「おわり」を表示する。
```

`examples/predicate.suru` には述語の例、`examples/cases.suru` には場合ごとの関数定義とパターンの条件の例、`examples/io.suru` には動作と手順の例、`examples/fib_input.suru` には個数を尋ねてフィボナッチ数列を表示する例、`examples/data.suru` には組・パターンマッチ・性質の例、`examples/punct.suru` には句読点の書き方の例、`examples/more.suru` には改行・インデント、局所定義、条件分岐と再帰、長いパイプラインの例、`examples/list.suru` には助詞の引数、リスト、高階関数の例があります。

## 文法のまとめ

| 書き方 | 意味 |
|---|---|
| `a を b で 除算する とは a / b` | 関数の定義。引数名の後に**格助詞**(を・に・で・から・へ・より)を付ける。関数名は「する」で終わる |
| `10 を 2 で 除算する` / `2 で 10 を 除算する` | 呼び出し。引数は助詞で対応するので語順は自由 |
| `答えする とは 42` | 引数なしの関数 |
| `税率 とは 0.1` | 値の定義(名前が「する」で終わらないもの) |
| `10 を 2 で 除算して 3 に 加算する` | パイプライン。「…して」の結果が次の関数の**「を」**に入る |
| `1 と 2 と 3`、`空` | リスト、空リスト |
| `a と b を 加算する とは a + b` | 「を」にリストを受け取り、分解して a・b に入れる |
| `リスト の 先頭` `の 残り` `の 最後` `の 長さ` | リストの性質 |
| `x を リスト に 追加する` / `挿入する` | 末尾 / 先頭に足した新しいリスト |
| `もし リスト が 空 ならば …` | 「が」は等しいかどうか(`==` と同じ) |
| `n が 偶数である とは …` | 述語(真偽を返す関数)の定義。主語は「が」 |
| `4 が 偶数である` / `3 が 偶数でない` / `偶数であること` | 述語の呼び出し / 否定 / 述語そのもの(値) |
| `三倍すること`、`1 を 加算すること` | 関数そのもの(値)。引数が足りなければ部分適用 |
| `x を 受け取って x * 2 を 返すこと` | 無名関数 |
| `リスト の それぞれ を 三倍する` | 要素ごとに呼び出して、結果のリストを返す(map) |
| `もし 条件 ならば 式 そうでなければ 式` | 条件分岐(式なので必ず値を返す) |
| `+ - * / % ^`、`× ÷`、全角の `＋－＊／` | 算術(`^` はべき乗)。リストどうしの `+` は連結 |
| `== != < > <= >=`、`= ≠ ≦ ≧` | 比較。結果は `真` / `偽` |
| `条件 かつ 条件`、`条件 または 条件` | 真偽の「かつ」「または」(左で決まれば右は計算しない) |
| `( … )` `（ … ）` | 括弧。呼び出しを算術式や引数に埋め込むときにも使う |
| `「文字列」` | 文字列。`+` で連結 |
| `#`・`＃`・`※` | 行末までコメント |
| `5を三倍する。` | 句読点の書き方。「。」で文が終わり、「、」は区切り。空白なしで詰めて書ける |
| `5を三倍します。`、`5を三倍しまして、表示します。`、`p とは 3 と 4 の 点 です。` | 丁寧語の文末。「します」は「する」、「しまして」は「して」と同じ。文末の「です」は読み捨てる |
| `… とは、本体。ただし、合計とは、a+b。` | 「ただし」で直前の定義に局所定義を付け足す |
| `（合計とは、a+b。合計/2）` | 括弧の中に「。」で文を並べたブロック(最後の文が値) |
| `『おやつの数』` | ひらがなを含む名前(『』で囲む) |
| `点 とは 横 と 縦 の 組` | 組(名前付きタプル)の型の定義 |
| `図形 とは 半径 の 円 か 幅 と 高 の 長方形`、`信号 とは 赤 か 黄 か 青` | 選択肢のある型(「か」で形を並べる) |
| `3 と 4 の 点` / `横 は 3 で 縦 は 4 の 点` | 組を作る(順番どおり / 名前つき) |
| `p の 横`、`横 は 10 の p` | フィールドを取り出す、1つだけ変えた新しい組を作る |
| `もし 形 が` + 深い行に `半径 の 円 ならば …` | パターンマッチ(場合分け) |
| `先頭 は x で 残り は 他 ならば …` | 空でないリストを先頭と残りに分解する |
| `半径 の 円 かつ 半径 > 10 ならば …` | パターンの条件(ガード) |
| `0 を 階乗する とは 1` + `n を 階乗する とは …` | 場合ごとの関数定義(引数にパターンを書く。上から順に使う) |
| `比較可能 という 性質 とは …` / `点 は 比較可能` | 性質(型クラス)の定義と実装 |
| `x を 表示する`、`入力する` | 動作(副作用)を作る。トップレベルに書くと行われる |
| `手順（文。文。…）` / `… とは 手順` + 深い行 | 文を順に行う(do 記法)。最後の文が全体の動作 |
| `名前 とは 入力した 結果` | 手順の中で動作を行い、その結果に名前を付ける(バインド) |
| `入力してから 表示する` | 前の動作の結果を次の関数の「を」に渡す(バインド) |
| `（入力する） の 結果 を 数値にする` | 動作の結果に関数を適用する(写像) |
| `x を 結果にする` | 何もせずに x を結果とする動作(pure / return) |
| `…。それから、…。` | 前の文の後に続けて行う |

### 組み込み関数

| 呼び出し | 意味 |
|---|---|
| `x を 表示する` | x を表示する動作(結果は x) |
| `入力する`、`「質問」 を 入力する` | 1行読む動作(結果は文字列)。「を」があれば先に表示する |
| `「12」 を 数値にする` | 文字列を数にする(全角も可。数にできなければエラー) |
| `動作のリスト を 実行する` | 動作を順に行う動作(結果は結果のリスト) |
| `x を 結果にする` | 何もせずに x を結果とする動作 |
| `m を f で 連鎖する` | m を行い、結果を f に渡す(性質「連鎖可能」の関数。リストなら f の結果をつなげる) |
| `x を 絶対値にする` | 絶対値 |
| `xs を 加算する`、`x を y に 加算する` | 合計(「を」がリストなら全部足す。「に」は省略可) |
| `xs を 乗算する`、`x を y に 乗算する` | 積 |
| `a から b を 減算する` | a - b |
| `a を b で 除算する` | a / b |
| `x を リスト に 追加する` / `挿入する` | 末尾 / 先頭に足したリスト |
| `関数 を x に 適用する` | 関数を x に適用(「に」を省くと引数なしで呼ぶ) |
| `リスト から 関数 で 選別する` | 関数が 真 を返す要素だけのリスト(filter) |
| `リスト を 関数 で 写像する` | 各要素に関数を適用したリスト(map)。性質「写像可能」の関数で、動作にも使える |
| `リスト を 初期値 から 関数 で 畳み込みする` | 左からの畳み込み(fold) |

組み込みと同じ名前の関数を定義すると、定義したほうが使われます。

## 決めたこと(仕様で曖昧だった点)

1. **引数は格助詞で区別する。** 使える助詞は「を・に・で・から・へ・より」。1つの関数で同じ助詞は1回までです(定義でも呼び出しでも、2回目はエラー)。足りない引数や、受け取らない助詞を渡すとエラーです。
2. **助詞は関数名にくっついていてよい。** `を加算する` と `を 加算する` は同じです。`で除算する`、`を返すこと` なども同様です。**ひらがなだけの関数名は使えません**(`へんかんする` はエラー。「する」の前に漢字かカタカナが必要です)。
3. **「…して」は関数合成(パイプライン)。** 前の結果は次の関数の「を」に入ります。次の区間に「を」の引数も書いてあるときは、**前の結果を先頭に並べたリスト**になります。`引数 と 引数 を加算して 引数 を加算する` は `加算(を = (加算(を = (引数, 引数)) と 引数))` です。式は必ず「…する」で終わります(「…して」で終わるとエラー)。
4. **「と」はリストを作る。** `1 と 2 と 3` は3要素のリストです。算術と比較は「と」より強く結びつくので、`1 + 1 と 2 * 3` は `（2 と 6）` です。1要素のリストは `1 を 空 に 追加する` で作ります。リストは変更できない値で、`（1 と 2 と 3）` のように表示します。
5. **定義の「a と b を」はリストの分解。** 渡されたリストの長さが合わないとエラーです。これで最初の例 `a と b を加算する とは a + b` は今まで通り動きます。
6. **読点「、」は句読点の書き方の区切り、中黒「・」は予約。** 「、」はリストの区切りには使いません(20 以降を参照)。「・」は文字列の外に書くとエラーです。将来ファイルを分けて読み込めるようにするとき、`数学・円周率` のような名前の区切りに使う予定です。
7. **「の」の後はリストの性質かフィールド名。** 先頭・残り・最後・長さ・それぞれ はリストの性質、それ以外の名前は組のフィールドです(`p の 横`)。算術より強く結びつきます(`リスト の 先頭 + 1` は `(リスト の 先頭) + 1`)。「の」の後が型の形の名前のときだけは組を作る意味になり、結びつきが変わります(28番)。
8. **「が」は等しいかどうか。** `リスト が 空` は `リスト == 空` と同じです。「もし」の直後の「が」はパターンマッチになりますが、パターンが値だけなら意味は同じです(31番)。
9. **「〜すること」は関数の値。** 区間の最後にある「こと」は、前に並んだ引数を受け取って部分適用になります(`1 を 加算すること`)。後ろに助詞が続く「こと」は、それ自体が外側の呼び出しの引数になり、前の引数は外側のものです(`リスト を 0 から 加算すること で 畳み込みする` の `0 から` は 畳み込み の引数)。部分適用した関数を外側の引数に渡すときは括弧で囲みます: `5 に （1 を 加算すること） を 適用する`。
10. **関数の値に値を渡すときは、まだ渡していない引数を定義の順に埋める。** 組み込みは表の順(加算する なら を → に)です。必須の引数が残れば、さらに部分適用になります。畳み込みでは、必須の引数が2つ以上ある関数には「累積値」「要素」を別々に、1つの関数には `（累積値 と 要素）` のリストとして渡します。
11. **「それぞれ」は1回の呼び出しにだけかかる。** `リスト の それぞれ を 三倍する` は三倍した結果のリストを返します。同じ呼び出しに「それぞれ」が2つあると、同じ位置の要素どうしで呼び出します(長さが違うとエラー)。呼び出しの引数以外に書いた `リスト の それぞれ` はリストそのものです。
12. **無名関数** `x を 受け取って 本体 を 返すこと`。引数の書き方は定義と同じです(`a と b を 受け取って` も可)。外側の変数を覚えます(クロージャ)。他の引数より前に書くときは括弧で囲みます。
13. **名前の予約。** 「する」「して」「すること」で終わる単語は常に関数とみなすので、変数名には使えません。`と` `とは` `の` `が` `を` `に` `で` `から` `へ` `より` `もし` `ならば` `そうでなければ` `受け取って` `返すこと` `ただし` `か` `は` `という` `組` `性質` `それから` `かつ` `または` `真` `偽` `空` も予約語です。「…した」で終わる単語(`入力した`)と「…してから」で終わる単語も関数の呼び出しです。「…である」「…でない」「…であること」で終わる単語は述語の呼び出しです(47番)。`結果` と `手順` は予約語ではなく、決まった位置(36番以降)でだけ特別な意味になります。
14. **算術は呼び出しより強く結びつく。** 呼び出しの結果を計算に使うときは `( 1 と 2 を加算する ) * 3` と括弧で囲みます。
15. **空白の書き方ではトークンはスペース区切り。** `a+b` のように詰めて書くと1つの名前になります。例外として括弧と「」『』は詰めて書いても区切ります。詰めて書きたいときは句読点の書き方(20)を使ってください。
16. **オフサイドルール。** 行頭のインデント幅で構造を決めます(半角スペース=1、全角スペース=2、タブ=4)。
   - 「とは」で行が終わると、次の深い行たちが本体ブロックになります。ブロックの中には局所定義を並べられ、**最後の行の式が値**になります。
   - 「とは」の後に同じ行で本体を書いた場合や、普通の式の行の後に深い行が続く場合、深い行は式の**続き**です。
   - 同じ深さの行が `ならば` / `そうでなければ` で始まるときは、前の行の続きとみなします(条件分岐を縦に並べて書けるように)。
   - 深さが前のどのブロックとも合わない行はエラーです。
17. **定義の順番は自由。** トップレベルの定義は先にすべて登録されるので、使う場所より後ろで定義しても、相互再帰でも動きます。
18. **割り算。** 整数どうしで割り切れるときは整数、そうでなければ小数になります。0 で割るとエラーです。
19. **エラーは日本語で、行番号と何文字目か付き。** `2行目 6文字目: 「存在しない数にする」は定義されていません` のように出し、ファイルを実行したときや対話モードでは、その行と位置の印(`^`)も表示します。全角の文字は2文字分の幅で印の位置を合わせます。実行時のエラーは、その式の始まり(算術ならその演算子)の位置を指します。

### 句読点の書き方

20. **「。」か「、」を含む行は句読点の書き方。** その行から始まる文は「。」で終わります。「。」までは改行をまたいでよく(字下げも自由)、1行に何文書いてもかまいません。「。」で終わらないまま最後まで来るとエラーです。「、」は空白と同じ区切りで、どこに書いてもよく、パターンマッチの場合の区切り(31番)のほかは意味を持ちません(`とは、` や `して、` の後に置くと読みやすい)。文字列の中の「。」「、」は関係ありません。「。」や「、」のない行は今まで通り空白とインデントの書き方なので、両方を1つのファイルに混ぜられます。
21. **単語は文字の種類の境目で切る。** 漢字・カタカナ・英字の並びは名前(英字の後の数字は名前の続き: `x1`)、数字の並びは数、記号の並びは演算子です。ひらがなの並びは 助詞(を・に・で・から・へ・より)、キーワード(と・とは・の・が・もし・ならば・そうでなければ・それぞれ・ただし・か・は・という)、「する/して/すること」に分けます。`長さ` `残り` `受け取って` `返すこと` と組み込みの `畳み込み` はひらがなを含みますが、決まった言葉として読みます。
22. **関数名は「する」の直前の名前から。** `リストを三倍する` は `リスト を 三倍する` です。「する」と同じひらがなの並びにある前の部分は関数名に入ります(`三倍にする` `絶対値にする`)。
23. **名前は漢字・カタカナ・英字で書く。** 送り仮名などのひらがなは助詞と区別できないので、ひらがなを含む名前は 『おやつの数』 のように『』で囲みます(「」は文字列なので『』にしました)。ひらがなの混ざった関数名は 『割る数に』する のように書けます(空白の書き方の `割る数にする` と同じ関数です)。
24. **ひらがなだけの名前はエラー。** どちらの書き方でも、ひらがなだけの名前(`するめいか とは 3`、`あ を 受け取って …`)を定義しようとすると、漢字かカタカナを使うか『』で囲むよう案内するエラーになります。『』で囲めばひらがなだけの変数名も使えますが、**ひらがなだけの関数名は『』で囲んでも使えません**。
25. **局所定義は「ただし」で付け足す。** `aとbを平均するとは、合計/2。ただし、合計とは、a+b。` の「ただし」の文は、直前の(ただしでない)定義の中の局所定義になります。続けて何個でも書けます。空白の書き方でも `ただし 合計 とは a + b` の行として使えます。定義でない文の後に「ただし」を書くとエラーです。
26. **括弧の中に文を並べられる。** 括弧の中に「。」か「とは」があれば、「。」で区切った文の並び(ブロック)として読み、最後の文の値が括弧の値になります: `（積とは、a*b。積^0.5）`。局所定義の中にさらに局所定義を書くときや、式の途中で名前を付けたいときに使います。
27. **「もし」は閉じなくてよい。** 「もし … ならば … そうでなければ …」は必ず両方の枝があるので、入れ子にしても区切りが一意に決まります。「そうでなければ」の後は文の終わり(か閉じ括弧)まで続くので、途中で終わらせたいときは括弧で囲みます。パターンマッチの場合分け(31番)は、形が全部そろっていれば「そうでなければ」を省けます。

### 組・パターンマッチ・性質

28. **組の型は「… の 組」、選択肢のある型は「か」で定義する。** `点 とは 横 と 縦 の 組` は、横・縦を持つ型「点」です(形の名前も「点」)。`図形 とは 半径 の 円 か 幅 と 高 の 長方形` は、円か長方形のどちらかの形をとる型です。中身のない形だけを並べると列挙型になります(`信号 とは 赤 か 黄 か 青`、`赤` はそのまま値)。型の定義は一番外側に書き、どこで使うより後ろに書いてもかまいません。型名・形の名前・フィールド名は変数名と同じ決まり(ひらがなを含むなら『』)で、形の名前はプログラム全体で1つの型にしか使えません。フィールド名を型や形の名前と同じにするとエラーです。
29. **組を作る。** 順番どおりなら `3 と 4 の 点`、名前つきなら `横 は 3 で 縦 は 4 の 点`(順番は自由。全部のフィールドが必要)です。**「… の 形の名前」は、「と」で並べた左側の値の全体にかかります**(`3 と 4 の 点` は `（3 と 4） の 点`)。そのため、組を「と」で並べるときは `（1 と 2 の 点） と （3 と 4 の 点）` と括弧で囲みます(囲まないとエラーで案内します)。`（3 と 4） の 点` のようにリストを1つ渡しても作れます。`名前 は 値` の後の「で」は、次に `名前 は` が続くときだけ組の続きと読みます。
30. **組は変更できない値。** `p の 横` で取り出し、`横 は 10 の p` で横だけ変えた新しい組を作ります(p はそのまま)。中身が同じなら `が` で等しくなります。表示は `（横 は 3 で 縦 は 4 の 点）` で、そのまま書き戻せます。
31. **パターンマッチは「もし 値 が パターン ならば …」。** `もし 形 が` の後の深い行(句読点の書き方では「、」の区切り)に `パターン ならば 式` を並べ、上から順に最初に当てはまった場合を使います。最後に `そうでなければ …` を書くと、残りすべてに当てはまります。1つだけなら `もし 形 が 半径 の 円 ならば 半径 そうでなければ 0` と1行でも書けます。場合の本体の途中で式を区切りの先まで続けたいときや、場合の本体にさらに場合分けを書くときは括弧で囲みます。
   - パターンの `… の 形の名前` と `名前 は …` の中の名前だけが新しい変数になり、その場合の式の中で使えます。`空`、数、文字列、`真`/`偽`、中身のない形(`赤`)、すでにある変数、`a と b` のような値は「等しいか」を調べます(今までの `もし xs が 空 ならば …` は意味が変わりません)。
   - 入れ子は括弧で書きます: `（x と y の 点） と r の 円`。同じ名前を2回使うとエラーです。
   - `先頭 は x で 残り は 他` は、空でないリストを先頭と残りに分けます。名前つきのパターンでは `の 形の名前` を省けて、省くと「そのフィールドを持つ値なら何でも」になります。
   - 選択肢のある型の場合分けで形が足りず、`そうでなければ` もないときは、読み込み時に「「長方形」の場合がありません」のエラーになります。どれにも当てはまらない値が来ると実行時エラーです。
32. **性質(型クラス)は「… という 性質 とは」で定義する。** 深い行に、関数の宣言(本体なし: `a と b を 比較する`)と、既定の実装(`… とは …`)を並べます。句読点の書き方では `比較可能という性質とは、aとbを比較する。ただし、…とは、…。` のように「ただし」で付け足します(「ただし」の後には本体のない宣言も書けます)。
33. **性質の実装は「型 は 性質」。** `点 は 比較可能` の下の深い行(句読点の書き方では「ただし」)に、その型での関数を定義します。助詞は宣言と同じにします。宣言だけの関数を定義しないとエラーです。組み込みの型名は `数` `文字列` `真偽` `リスト` `関数` です。
34. **どの実装を使うかは「を」の値の型で決める。** 「を」を `a と b` で分解する関数なら最初の要素の型です(「を」がない関数は最初の引数)。実装していない型で呼ぶと「「文字列」は性質「比較可能」を持っていません」のエラーです。性質の関数は普通の関数と同じく `比較すること` で値にできます。性質の関数や中身のない形の名前は、ほかの定義で上書きできません。
35. **組み込みの性質「表示可能」。** 関数は `x を 文字列化する` の1つで、実装しなくてもすべての型が持っています(いつもの表示の文字列を返す)。実装すると、`表示する` やトップレベルの結果の表示、リストの中の表示がそれを使います。

### 動作(副作用)と手順

36. **副作用は「動作」という値。** `x を 表示する` や `入力する` は、その場では何もせず、表示や入力をする**動作**を返します。トップレベルの文の値が動作なら、その場で行います(その結果は表示しません)。動作でない値は今まで通り表示します。動作の型名は `動作` です。`（「a」 を 表示する） と 1` のように、作っただけで使わない動作は行われません。
37. **「…してから」はバインド。** `入力してから 数値にして 表示する` は、入力を行い、その結果を「数値にして 表示する」の「を」に渡します。「してから」の後ろは全部、前の結果を受け取る続きです。前の結果が動作でなければエラーです(純粋な値には「して」を使います)。続きが動作でない値を返したときは、それが全体の結果になります。
38. **「手順（文。文。…）」は do 記法。** 文を上から順に行い、最後の文が全体の動作(値)になります。空白の書き方では `挨拶する とは 手順` の後の深い行に文を並べます。手順の途中の文は動作でなければなりません(値を計算するだけの文はエラー)。「手順（」だけの行の後に句読点の書き方の行が続くときは、その行も句読点の書き方として読みます。
39. **「…した 結果」は、手順の中で動作を行った結果。** `名前 とは 入力した 結果` で結果に名前を付けます(普通の定義と同じ「とは」)。名詞なので、`入力した結果を数値にして、表示する。` のように手順の文の中のどこにでも書け、文の中で先に書いたものから行います。手順の外、関数の本体や「もし」の枝の中に書くとエラーです(そこを「手順（…）」で囲みます)。算術に使うときは `（入力した結果）+1` と括弧で囲みます。
40. **「の 結果」は写像。** `（入力する） の 結果 を 数値にする` は、入力の結果を数値にする動作です(「の それぞれ」がリストの要素ごとに呼ぶのと同じ形)。呼び出しの引数にだけ書けます。2つ以上の引数に書くと、前から順に行います。`結果` というフィールドを持つ組なら、今まで通りフィールドの取り出しです。
41. **「。それから、」は続けて行う。** `「やあ」を表示する。それから、「またね」を表示する。` は2つを順に行う1つの文になります。定義の後に書くと本体の続きになります(`ただし` と同じく直前の文に付け足す)。空白の書き方では `それから …` の行として書きます。
42. **性質「写像可能」と「連鎖可能」。** 組み込みの性質で、`写像可能` は `m を f で 写像する`、`連鎖可能` は `m を f で 連鎖する` と `x を 結果にする` を持ちます。リストと動作が実装しています(リストの連鎖は f の結果をつなげたリスト)。自分の型でも `『たぶん』 は 連鎖可能` として `連鎖する` を定義すれば、手順・「してから」・「の 結果」が使えます。`結果にする` は「を」の型で選べないので、いつも「何もしない動作」を作り、連鎖したときに相手の型に合わせます(その型で `x を 結果にする` を定義していればそれを使います)。

### 場合ごとの関数定義とパターンの条件

43. **パターンの条件は「かつ」。** 場合分けの `パターン かつ 条件 ならば 式` は、パターンに当てはまり、しかも条件が 真 のときだけその場合を使います。条件の中ではパターンで付けた名前が使えます(`半径 の 円 かつ 半径 > 10 ならば …`)。条件が 偽 なら次の場合に進みます。条件つきの場合は、形がそろっているかの確かめ(31番)の数に入れません。
44. **「かつ」「または」は真偽の計算。** 比較より弱く、「と」より強く結びつき、「かつ」のほうが「または」より強く結びつきます(`a または b かつ c` は `a または （b かつ c）`)。左で結果が決まれば右は計算しません。両側は 真 か 偽 でなければエラーです。パターンの直後の「かつ」は条件の始まりと読むので、`もし n が 0 かつ m > 1 ならば …` は「n が 0 で、しかも m > 1 なら」の意味になります(どちらに読んでも結果は同じです)。
45. **引数に値や形を書くと、場合ごとの関数定義になる。** `0 を 階乗する とは 1` のように、引数名の代わりにパターン(数、文字列、`空`、`真`/`偽`、中身のない形、`… の 形の名前`、`名前 は …`)を書けます。括弧の要る形は `（r の 円） を 面積にする` のように囲みます。パターンの中の名前だけが新しい変数で、名前だけの引数はどんな値にも当てはまります。`a と b を` は今までどおり2要素のリストを分けますが、場合ごとの定義の中では長さが違えば次の定義に進みます。
46. **同じ関数の定義は続けて書き、上から順に使う。** 続けて書いた同じ名前の関数定義は1つの関数にまとまり、呼び出すと、引数がすべて当てはまる最初の定義を使います。どの定義も同じ助詞を使います(違うとエラー)。すべての引数が名前だけの定義の後ろに、さらに定義を書くとエラーです(使われないため)。引数が1つで形の場合分けになっているなら、足りない形は読み込み時に「「面積にする」に「長方形」の場合の定義がありません」のエラーになり、どれにも当てはまらない値が来ると実行時エラーです。同じ関数を離れた場所でもう一度定義するとエラーです。局所定義(ただし)や性質の実装の中でも使えます。

### 述語

47. **「…である」で終わる名前は述語。** `n が 偶数である とは n % 2 が 0` のように、主語を「が」で受け、真か偽を返す関数です(ほかの助詞の引数も使えます: `a が b で 割切である`)。真偽以外を返すと実行時エラーです。名前の決まりは「する」の関数と同じで、「である」の前に漢字かカタカナが必要です。
48. **呼び出しは「…である」「…でない」、値は「…であること」。** `4 が 偶数である` は 真、`3 が 偶数でない` は否定です(「でない」は定義しなくても使えます。「…でない とは」と定義するとエラー)。`偶数であること` は「すること」と同じく述語そのもので、`リスト から 偶数であること で 選別する` のように渡せます。部分適用もできます。
49. **述語の前の「が」は主語。** 「が」の後ろを読んでいって、呼び出しの終わりが述語なら、その「が」は主語の助詞です。そうでなければ今までどおり「等しいか」です(`リスト が 空` は変わりません)。`もし n が 偶数である ならば …` もそのまま書けます。「…して」の結果は、述語では「を」でなく「が」に入ります(`5 を 三倍して 偶数である`)。
50. **述語どうしは「かつ」「または」でつなげる。** `n が 正である かつ n が 偶数でない` のように、呼び出しを含む条件も「かつ」「または」でつなげます(44番と同じ結びつきの強さ)。パターンの条件(43番)にも書けます。

### 丁寧語の文末

60. **「します」「しまして」は「する」「して」と同じ。** `5を三倍します。` は `5を三倍する。`、`5を三倍しまして、表示します。` は `5を三倍して、表示する。` と同じ意味です。「しましてから」は「してから」と同じです。どちらの書き方でも使えます(空白の書き方なら `5 を 三倍します`)。関数の名前は今までどおり「する」で終わる名前で、定義も `n を 三倍する とは …` のまま書けます(`n を 三倍します とは …` と書いてもかまいません)。
61. **文末の「です」は読み捨てる。** `p とは 3 と 4 の 点 です。`、`x とは 7です。`、`もしn>0ならば「正」です、そうでなければ「負」です。` のように、「。」「、」「）」「そうでなければ」の前か、空白の書き方の行の終わりに書いた「です」は飾りとして読み飛ばします。それ以外の場所(`3 です と 4`)に書くとエラーです。「です」「ます」はひらがななので、ひらがなを含む名前を『』で囲む決まり(23番)のおかげで名前とぶつかりません。

### 型の検査(第1段階)

51. **`python3 suru.py --検査 ファイル` で、実行する前に型の間違いを探す。** 型は書かなくても推論します(Hindley–Milner)。今は検査だけで、実行(`python3 suru.py ファイル`)は今までどおり型を調べません。全部の例が通るようになったら、実行の前に必ず検査する予定です。
52. **型の名前。** `数` `文字列` `真偽`、`数 の リスト`、`文字列 の 動作`、組や選択肢のある型はその型名、関数は `（数 を 受け取って 数 を 返すこと）` と表示します。まだ決まっていない型は 甲・乙・丙 … です。
53. **リストの要素の型はそろえる。** `1 と 「a」` はエラーです。違う型の値をまとめるときは組か選択肢のある型を使います。
54. **「+」は同じ型どうし。** 数・文字列・リストを、同じ型どうしでだけ足せます。数を文字列につなぐときは `（x を 文字列化する）` を使います(実行のときは今までどおりつなげます)。`<` などの大小の比較は数どうし、`が`・`==` は同じ型どうしです。
55. **呼び出しは助詞ごとに調べる。** 受け取らない助詞、足りない引数、型の違う引数は、実行する前にエラーになります。関数の値(`三倍すること`)を渡すときは、助詞ではなく引数の順番で合わせます。`加算する` は「を」がリストなら全部を足し、「に」があれば2つを足すように、特別に調べます。
56. **定義は多相。** `x を 恒等にする とは x` は数にも文字列にも使えます。一番外と「ただし」の定義は、互いに呼び合うものをまとめて推論します。組のフィールドの型は、プログラム全体で1つの型にそろえます(型の引数をとる型は第3段階)。
57. **性質の関数は、実装の型で調べる(第2段階)。** `a と b を 比較する` のような性質の関数の呼び出しは、「を」の値の型(34番と同じ決め方)が分かったところで、その型の実装(なければ既定の実装)の型と合わせます。実装していない型で呼ぶと「文字列は性質「比較可能」を持っていません」のエラーになります。性質の関数を使う多相な関数(`a と b を 大きい方にする`)は「この性質を持つ型なら何でもよい」という条件つきの型になり、呼んだところで確かめます。`表示可能` の `文字列化する` の実装は文字列を返す必要があります。
58. **型の条件も呼んだところで確かめる。** `x の 長さ`(文字列かリスト)や `a + b`(数・文字列・リスト)のように型の種類にしばりのある多相な関数は、そのしばりを型に持たせて、呼んだところで確かめます(`「測る数にする」に渡した値: …`)。
59. **まだ調べないもの。** 動作の結果の型(手順・「してから」・「した 結果」・`結果にする`)と、`写像可能`・`連鎖可能` を自分の型で実装したときの型は、どんな型とも合うものとして扱います(第3段階で、型の引数をとる型と一緒に調べます)。
