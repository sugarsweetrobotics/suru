# 日本語関数型プログラミング言語「する」(プロトタイプ)

Python 3.10 以降だけで動くインタプリタです(外部ライブラリ不要。テストに pytest を使います)。

```sh
python3 suru.py examples/basic.suru   # ファイルを実行(トップレベルの式の値を1行ずつ表示)
python3 suru.py                       # 対話モード
python3 -m pytest tests               # テスト
```

## 例

```
a　と　b　を加算する　とは　a + b

引数　を三倍する　とは　引数　と　引数　を加算して　引数　を加算する

1　と　2　を加算する      # → 3
5　を三倍する             # → 15
```

`examples/more.suru` には改行・インデント、局所定義、条件分岐と再帰(階乗)、長いパイプラインの例があります。

## 文法のまとめ

| 書き方 | 意味 |
|---|---|
| `a と b を加算する とは a + b` | 関数の定義。関数名は必ず「する」で終わる |
| `答えする とは 42` | 引数なしの関数 |
| `税率 とは 0.1` | 値の定義(名前が「する」で終わらないもの) |
| `1 と 2 を加算する` | 呼び出し。引数は「と」で区切り、最後の引数に「を」が付く |
| `A を三倍して 二乗して 1 を加算する` | パイプライン。「…して」の結果が次の関数の**第1引数**になる |
| `もし 条件 ならば 式 そうでなければ 式` | 条件分岐(式なので必ず値を返す) |
| `+ - * / % ^`、`× ÷`、全角の `＋－＊／` | 算術(`^` はべき乗) |
| `== != < > <= >=`、`= ≠ ≦ ≧` | 比較。結果は `真` / `偽` |
| `( … )` `（ … ）` | 括弧。呼び出しを算術式に埋め込むときにも使う |
| `「文字列」` | 文字列。`+` で連結 |
| `#`・`＃`・`※` | 行末までコメント |

組み込み関数: `x を表示する`(表示して値をそのまま返す)、`x を絶対値にする`。

## 決めたこと(仕様で曖昧だった点)

1. **「を」は関数名にくっついていてよい。** 例が `を加算する` と書いているので、`を加算する` と `を 加算する` はどちらも関数「加算する」の呼び出しとして扱います。「と」「とは」は独立したトークンです。
2. **「…して」は関数合成(パイプライン)。** `X と Y を加算して Z を加算する` は `加算(加算(X, Y), Z)` です。前の結果は常に**第1引数**に入り、後ろに書いた引数がその後に続きます。追加の引数がなければ `5 を三倍して 二乗する` のように「を」なしで書けます。式は必ず「…する」で終わります(「…して」で終わるとエラー)。
3. **名前の予約。** 「する」「して」で終わる単語は常に関数呼び出しとみなすので、変数名には使えません。`と` `を` `とは` `もし` `ならば` `そうでなければ` `真` `偽` も予約語です。
4. **算術は呼び出しより強く結びつく。** `1 + 1 と 2 * 3 を加算する` は `加算(2, 6)` です。逆に呼び出しの結果を計算に使うときは `( 1 と 2 を加算する ) * 3` と括弧で囲みます。
5. **トークンはスペース区切りが原則。** `a+b` のように詰めて書くと1つの名前になります。例外として括弧と「」は詰めて書いても区切ります。
6. **オフサイドルール。** 行頭のインデント幅で構造を決めます(半角スペース=1、全角スペース=2、タブ=4)。
   - 「とは」で行が終わると、次の深い行たちが本体ブロックになります。ブロックの中には局所定義を並べられ、**最後の行の式が値**になります。
   - 「とは」の後に同じ行で本体を書いた場合や、普通の式の行の後に深い行が続く場合、深い行は式の**続き**です。
   - 同じ深さの行が `ならば` / `そうでなければ` で始まるときは、前の行の続きとみなします(条件分岐を縦に並べて書けるように)。
   - 深さが前のどのブロックとも合わない行はエラーです。
7. **定義の順番は自由。** トップレベルの定義は先にすべて登録されるので、使う場所より後ろで定義しても、相互再帰でも動きます。
8. **条件分岐と再帰を追加。** 仕様にはありませんでしたが、関数型言語として再帰が書けないと実用にならないので `もし … ならば … そうでなければ …` を入れました。
9. **割り算。** 整数どうしで割り切れるときは整数、そうでなければ小数になります。0 で割るとエラーです。
10. **エラーは日本語で、行番号付き。** 引数の数の違い、未定義の名前、「して」で終わる式などを検出します。
